# Used Car Data Preprocessing

## Description
A Python data preprocessing project that prepares a used car dataset for machine learning. It includes outlier detection, missing-value handling, categorical encoding, feature scaling, and train-test splitting.

## Features
- Dataset inspection
- Missing-value handling
- IQR-based outlier detection
- One-Hot Encoding
- StandardScaler feature scaling
- Feature and target separation
- Train-test split
- Data leakage prevention
- Processed dataset export

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab / Jupyter Notebook
